The first public release. ／ 最初の公開版です。

**English**

Control browser tabs with three-finger trackpad gestures.

- Swipe left / right with 3 fingers: next / previous tab
- Swipe down: close the tab. Swipe up: reopen the closed tab
- Tap with 3 fingers: new tab. Click with 3 fingers: open the link in a new tab
- Pinch with your thumb and 2 fingers: reload
- Extras, off by default: ⌘ alone to switch Eisu / Kana, the Notch Shelf, and a 5-finger swipe to sleep the display
- English and Japanese, and automatic updates

On first launch, allow Accessibility access and move macOS's own three-finger gestures to four fingers. TriTab walks you through both.

**日本語**

トラックパッドの3本指ジェスチャーで、ブラウザなどのタブを操作できます。

- 3本指で左右にスワイプ：次／前のタブ
- 下へスワイプ：タブを閉じる。上へスワイプ：閉じたタブを復元
- 3本指でタップ：新しいタブ。3本指でクリック：リンクを新しいタブで開く
- 親指＋2本指でつまむ：再読み込み
- 便利機能（最初はオフ）：⌘単体で英数／かな、ノッチの棚、5本指スワイプでディスプレイをスリープ
- 英語と日本語に対応。自動アップデートに対応

はじめて起動したら、アクセシビリティを許可し、macOS 標準の3本指ジェスチャーを4本指に移してください。どちらも TriTab が案内します。

**Install ／ インストール**

- DMG: download `TriTab-0.1.0.dmg` below and drag TriTab to Applications ／ 下の `TriTab-0.1.0.dmg` を開き、TriTab を「アプリケーション」へドラッグ
- Homebrew: `brew install --cask ikora128/tap/tritab`

Requires macOS 13 Ventura or later, on Apple silicon or Intel. ／ macOS 13 Ventura 以降（Apple シリコン・Intel）。
