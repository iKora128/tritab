# TriTab

**3本指で、タブを自在に。** ／ [English](README.md)

トラックパッドのジェスチャーでタブを操作する、macOS のメニューバー常駐アプリです。無料で使えるオープンソース（MIT ライセンス）です。
常駐時のメモリは約 13 MB です（実測。BetterTouchTool は約 48 MB）。

## インストール

- **DMG**: [Releases](https://github.com/iKora128/tritab/releases/latest) から最新の `TriTab-x.y.z.dmg` をダウンロードして開き、TriTab を「アプリケーション」へドラッグします。
- **Homebrew**: `brew install --cask ikora128/tap/tritab`

macOS 13 Ventura 以降（Apple シリコン・Intel）で動きます。Developer ID で署名し、Apple の公証を通してあります。アップデートは自動で届きます。

## 最初にやること

1. **アクセシビリティを許可する**：システム設定 › プライバシーとセキュリティ › アクセシビリティ。キー操作を送るために使います。
2. **macOS 標準の3本指ジェスチャーを4本指に移す**：システム設定 › トラックパッド › その他のジェスチャ。競合していれば TriTab が知らせます。
3. **3本指ドラッグを使っている場合**：設定画面で指の本数を4本にします。

## タブ操作（既定でオン）

| ジェスチャー | 動作 |
|---|---|
| 3本指で左へスワイプ | 次（右）のタブ |
| 3本指で右へスワイプ | 前（左）のタブ |
| 3本指で下へスワイプ | タブを閉じる |
| 3本指で上へスワイプ | 閉じたタブを復元 |
| 3本指でタップ | 新しいタブ |
| 3本指でクリック（押し込む） | ⌘+クリック（リンクを新しいタブで開く） |
| 4本指でクリック | 閉じたタブを復元 |
| 親指＋2本指でつまむ | 再読み込み |

- スワイプ1回につき1回だけ動きます。ゆっくりずれたり、指を置き直したりしただけでは発火しません。
- 3本指が触れている間は、2本指スクロールによる「戻る／進む」の誤動作を TriTab が止めます。
- アプリごとにショートカットの違いを切り替えます（例：Arc は ⌘⌥↓、VS Code は ⌘⌥→）。登録のないアプリには ⌃Tab / ⌘W / ⇧⌘T を送ります。
- ターミナル系のアプリでは「閉じる」と「復元」は動きません。Slack・Discord・メールでは何もしません。

## 便利機能（既定でオフ、設定画面でオン）

- **⌘単体で英数／かな**：左⌘で英数、右⌘でかな。Karabiner-Elements の定番ルールと同じ動きです。
- **4本指タップで英数／かなを切り替え**
- **ノッチの棚**：ファイルをドラッグして少し上へ動かすと、ノッチから棚が出てきて一時置きできます。ノッチにマウスを乗せても開き、開いているあいだは ⌘V でクリップボードの中身（ファイル・画像・テキスト）を置けます。
- **5本指で上スワイプしてディスプレイをスリープ**

## 設定

メニューバーのアイコンから「設定…」（⌘,）を開きます。設定画面は別のプロセスで開き、閉じるとそのプロセスごと終了します。SwiftUI のメモリを常駐側に残さないためです。

画面は日本語と英語に対応しています。macOS の言語設定に合わせて切り替わります。

## プライバシー

- TriTab は、ジェスチャーとショートカットを判定するためだけに、トラックパッドのタッチとキーボード・マウスの操作を Mac の中で読み取ります。記録したり、どこかへ送ったりはしません。
- 通信するのはアップデートの確認だけです。自動確認を許可した場合（2回目の起動時に尋ねます）は1日1回、またはメニューの「アップデートを確認…」を選んだときに、`https://github.com/iKora128/tritab/releases/latest/download/appcast.xml` を読み込みます。利用状況の収集や、システム情報の送信はしません。
- データはすべて Mac の中に置きます。設定は `~/Library/Preferences/io.github.ikora128.TriTab.plist`、ノッチの棚のメモは `~/Library/Application Support/io.github.ikora128.TriTab`、棚の一時ファイルは `~/Library/Caches/io.github.ikora128.TriTab` です。

## ビルド

```sh
./scripts/setup-dev-signing.sh    # 初回だけ。開発用の署名証明書を専用キーチェーンに作る
./scripts/test.sh                 # テスト
./scripts/build-app.sh --install  # ビルドして /Applications に入れて起動
TRITAB_DEBUG=1 /Applications/TriTab.app/Contents/MacOS/TriTab  # ログを出しながら起動
```

Xcode は不要で、Command Line Tools だけでビルドできます。開発用の証明書で署名すると、ビルドし直してもアクセシビリティの許可が外れません。配布用のビルドの手順は [docs/RELEASE.md](docs/RELEASE.md) にあります。

## 仕組み

- **タッチの読み取り**：非公開の `MultitouchSupport.framework` を `dlopen` で読み込みます（`Sources/MTBridge`）。
- **ジェスチャーの判定**：`Sources/TriTabCore/GestureEngine.swift`。UI に依存しない純粋なロジックで、テストがあります。
- **クリックとキー入力**：CGEventTap で処理します。⌘クリック、⌘単体の英かな、スクロールの抑止を受け持ちます。
- **キーの送信**：CGEvent を使います。
- **アップデート**：[Sparkle](https://sparkle-project.org) を使います。更新ファイルと更新情報（appcast）の両方に EdDSA の署名を付けています。
- 非公開 API を使うため、Mac App Store では配布できません。macOS のアップデートで動かなくなった場合は、TriTab の更新で対応します。
